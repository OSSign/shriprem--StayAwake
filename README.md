# OSSign Information
## What's this?
This is a repository used for creating signed binaries for the [shriprem/StayAwake](https://github.com/shriprem/StayAwake/) project.

## Where are the signed binaries published?
The signed drivers are published by the author on [shriprem/StayAwake](https://github.com/shriprem/StayAwake).

You can find the latest workflow runs for the build and signing process in the [Actions tab](https://github.com/ossign/shriprem--StayAwake/actions).
